# requimd for VS Code

Requirements as Markdown files in git, checked while you write: live
diagnostics, completion of IDs and links, hover, go to definition, find
references, rename, code lens on use case steps and highlighting of weak
words, for every requimd project in the workspace.

The package contains the `requimd` executable for its platform; nothing
else needs installing. A project is a directory with a `requimd.toml`.

Setup, settings and features: [docs/vscode.md](https://github.com/josh-cest-moi/requimd/blob/main/docs/vscode.md).
